## How it works

`main.py` (Python standard library only, deterministic, no network) writes the
single word to `/output/entry.txt`, per the competition contract. The gate
requires UTF-8 text of 1–24 characters — this entry is 5 characters.

```sh
python3 main.py
cat /output/entry.txt
```
